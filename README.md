# DevSphere

![Logo](assets/images/logo.png)

DevSphere es mi bitácora personal de desarrollo, donde documento mi viaje de aprendizaje y crecimiento como desarrollador. Aunque es pública, su principal propósito es servir como un repositorio personal de conocimiento, notas y recursos que he ido acumulando a lo largo de mi carrera y alguno más que quiero aprender aún.

## 📚 Contenido

Esta bitácora incluye:

- **Paquetes de Go**: Mis notas y documentación sobre paquetes de Go que he utilizado o estoy aprendiendo
- **Ejemplos de Código**: Fragmentos de código y ejemplos que me han sido útiles y quiero tener a mano
- **Tecnologías**: Notas y recursos sobre diferentes tecnologías que estoy explorando
- **Hojas de Trucos**: Atajos y referencias rápidas que me ayudan a recordar conceptos importantes

## 🛠️ Tecnologías Utilizadas

- [Jekyll](https://jekyllrb.com/) - Motor de sitios estáticos
- [GitHub Pages](https://pages.github.com/) - Hospedaje
- [SASS](https://sass-lang.com/) - Preprocesador CSS
- [Mermaid](https://mermaid-js.github.io/) - Diagramas y gráficos

## 📦 Estructura del Proyecto

```
.
├── _config.yml          # Configuración de Jekyll
├── _layouts/           # Plantillas de diseño
├── _includes/          # Componentes reutilizables
├── _pages/            # Páginas del sitio
├── _sass/             # Estilos SASS
├── assets/            # Recursos estáticos
└── _data/             # Datos del sitio
```

## 🚀 Instalación Local

Si quieres explorar o usar este repositorio localmente:

1. Clona el repositorio:
```bash
git clone https://github.com/Miguelp-Dev/miguelp-dev.github.io.git
```

2. Instala las dependencias:
```bash
bundle install
```

3. Ejecuta el servidor local:
```bash
bundle exec jekyll serve
```
